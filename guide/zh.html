什么是色彩分析？

在自然光下，把一条鲜红色的围巾贴近脸部，然后照照镜子。你的肤色会随之起变化。对适合的人来说，它能提亮整张脸，皮肤显得更通透，眼睛也更有神；对不适合的人来说，它会在脸上投下阴影，凸显泛红，让气色黯淡无光。

这种变化，就是色彩分析的原理。

每种颜色都有三种属性：偏暖还是偏冷，偏浅还是偏深，偏明艳还是偏柔和。你与生俱来的自然色彩也具有同样的三种属性。当你穿的颜色与你自身的色彩相契合时，整个人都会焕然一新。

这些属性会将你指向十二种季型中的一种，其中之一就是你的季型。这份指南会告诉你是哪一种。

开始分析之前

每次测试色卡时，都请遵循以下四个步骤。如果测试条件不对，结果也会不准。

1. 找到合适的光线

坐在窗边的自然光下。不要阳光直射，而是间接、均匀的光线。不开台灯，不用顶灯，脸上不要有阴影。

2. 卸掉所有妆容

卸掉粉底、遮瑕、腮红，以及任何带颜色的护肤品或自助美黑产品。这些都会改变皮肤在色卡下呈现的效果。

3. 穿一件中性色上衣

白色、灰色或米色。任何有颜色的衣服都会反射到皮肤上，改变你看到的效果。

4. 扎起染色的头发

如果你的头发染过色或挑染过，请把头发扎起来，以免影响脸部附近颜色的呈现。

现在，你已经准备好开始了。

7 步完成色彩分析

请按顺序完成每一步，不要跳步。

第 1 步，共 7 步

第 1 步 — 找到你的肤色底调

肤色底调指的是皮肤偏暖或偏冷的程度，它是色彩分析中最重要的属性。

以下两种方法可以帮你找到自己的底调：

1. 晒太阳后会怎样？

  • 容易晒红 → 冷调
  • 容易晒黑 → 暖调

2. 金色还是银色？

大多数人凭直觉就知道答案。想想你自然而然会选哪种金属，你拥有更多的是哪种首饰，哪一种让你觉得“就是我”。

如果不确定，可以把金饰贴在裸露的手腕上，再换成银饰。哪一种与皮肤融为一体、看起来本就属于那里？哪一种看起来有点违和，像是浮在皮肤表面，而不是与皮肤融合？

  • 金色看起来更融合 → 暖调
  • 银色看起来更融合 → 冷调

中性调？

有些人戴金色和银色都很好看，既会晒红也会晒黑。如果你是这样，你仍然会稍微偏向某一边，哪怕非常细微。请选择你最偏向的那一边。

圈出你的结果：暖（WARM）/ 冷（COOL）

第 2 步，共 7 步

第 2 步 — 找到你的深浅度

深浅度指的是你整体色彩的深浅程度，即皮肤、头发和眼睛综合起来的效果。

不确定？试试这个小技巧。

给自己拍一张黑白照片：可以先拍普通照片再后期调成黑白，也可以先把相机切换到黑白模式。

  • 你的整体色彩看起来以浅为主吗？
  • 整体看起来以深为主吗？
  • 还是介于两者之间？

把皮肤、头发和眼睛放在一起看，而不是逐一单独看，相信你的第一印象。

浅：白皙的皮肤、浅色头发、浅色眼睛。
中等：既不特别浅也不特别深，介于中间。
深：较深的肤色、深色头发、深色眼睛。

圈出你的结果：浅（LIGHT）/ 中等（MEDIUM）/ 深（DEEP）

第 3 步，共 7 步

第 3 步 — 你的色彩公式

你的肤色底调和深浅度会直接指向你的色彩家族。

暖 + 浅 = 春季（Spring）
暖 + 深 = 秋季（Autumn）
冷 + 浅 = 夏季（Summer）
冷 + 深 = 冬季（Winter）

每个家族包含三个密切相关的季型。

* 这只是一个说明，现在还不用担心。在后面的步骤中测试色卡时，你就会找到自己确切的细分季型。

测试深浅度时结果是“中等”？

你正好处于两个家族之间。我们还需要再确认一点：

  • 明艳：你的色彩对比度高，五官特征彼此分明
  • 柔和：你的色彩融合度高，五官特征的色调彼此接近

请使用下面的公式：

暖 + 中等 + 明艳 = 春季（Spring）
暖 + 中等 + 柔和 = 秋季（Autumn）
冷 + 中等 + 明艳 = 冬季（Winter）
冷 + 中等 + 柔和 = 夏季（Summer）

第 6 步，共 7 步

第 6 步 — 如何使用色卡

拿上镜子，在自然光下进行测试。

  • 每次只拿一张卡片举到脸前，让脸位于圆圈的正中间
  • 看你的脸，而不是看卡片——你要观察的是它对皮肤产生的效果，而不是判断自己喜不喜欢这个颜色
  • 可能不止一张卡片看起来不错，这很正常，你要找的是带来最大变化的那一张

你要观察什么

适合的颜色会：
  • 让肤色更均匀
  • 淡化眼下阴影
  • 让眼睛更明亮
  • 让脸看起来更有精神
不适合的颜色会：
  • 让阴影看起来更深
  • 让肤色显得不均匀
  • 让注意力集中在颜色本身
  • 让瑕疵、泛红或黑眼圈更加明显

* 如果有帮助，可以拍张照片。有时候镜头能捕捉到肉眼忽略的细节。

你的三张色卡

找到自己的季型后，就可以取出属于你的三张一组的色卡：CORE（核心色）、NEUTRAL（中性色）和 ACCENT（点缀色），卡片上都有对应标注。它们的区别在于各自在你衣橱中扮演的角色。

你的核心色
你的日常色彩。针织衫、连衣裙、衬衫和叠穿单品——这些是你最常选择的颜色。
你的中性色
把它们看作衣橱的基础，是你会一次又一次反复穿搭的日常基本款。
你的点缀色
适用于亮点单品、特殊场合和配饰，例如一件醒目的上衣、一只鲜艳的包或一双吸睛的鞋子。

在你的色彩中生活

搭配穿搭的通用小贴士

想打造最佳色彩组合，可以用你的中性色搭配你自己色盘中的核心色或点缀色。

来自造型师的穿搭建议

  • 尝试同色系穿搭，也就是单色穿搭：选一种颜色，从头到脚穿它的不同深浅，全部取自你自己的色彩季型。
  • 同时混搭不同材质：针织配丝绸，麂皮配牛仔，皮革配柔软的面料。毫不费力，又低调地显出高级感。

你的特征

Bright Winter

净冬型

明艳 · 冷调 · 深邃

Bright Winter（净冬型）的主要特质是明艳与冷调。这类色彩是所有季型中最大胆的。色盘也同样如此，明亮而充满电感，宛如夜晚的城市灯火。
